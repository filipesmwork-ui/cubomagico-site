Política de privacidade

Última atualização: 11 de novembro de 2026

Esta política explica que dados pessoais recolhemos quando nos pedes contacto através deste site, para que os usamos e que direitos tens sobre eles.

Quem é o responsável

O responsável pelo tratamento dos dados é [nome legal da entidade], com o NIF [NIF] e sede em [morada], que opera o CUBO.AI.

Para qualquer questão sobre os teus dados, escreve para geral@cubomagico.ai.

Que dados recolhemos

Apenas os que nos envias no formulário de pedido de contacto:

  • nome;
  • email;
  • telefone, se o indicares;
  • nome da entidade ou empresa;
  • o tipo de apoio que procuras e a mensagem, se a escreveres;
  • a tua autorização para usarmos estes dados para responder ao pedido.

Não pedimos dados sensíveis. Pedimos-te que não os incluas na mensagem.

Para que os usamos

Usamos estes dados só para responder ao teu pedido e, se fizer sentido para a tua organização, para preparar uma proposta. Não os usamos para enviar publicidade nem os vendemos a ninguém.

O fundamento é o teu consentimento, dado ao marcar a caixa do formulário (artigo 6.º, n.º 1, alínea a) do RGPD), e as diligências pré-contratuais que nos pedes (alínea b).

Quem tem acesso

Os pedidos são entregues por email através do FormSubmit (formsubmit.co), um serviço que faz a ponte entre o formulário e a nossa caixa de correio. Este serviço trata os dados apenas para os entregar.

O site é alojado no GitHub Pages, da GitHub, Inc. As letras do site são carregadas a partir do Google Fonts, o que faz com que o teu navegador comunique o endereço IP à Google.

Alguns destes fornecedores podem tratar dados fora do Espaço Económico Europeu; quando isso acontece, fazem-no ao abrigo das garantias previstas no RGPD, como as cláusulas contratuais-tipo da Comissão Europeia.

Durante quanto tempo

Guardamos os dados do pedido durante 12 meses após o último contacto. Se passares a ser cliente, os dados passam a reger-se pelo contrato que celebrarmos. Se retirares o consentimento antes disso, apagamo-los.

Os teus direitos

Podes, a qualquer momento e sem custos:

  • saber que dados temos sobre ti e pedir uma cópia;
  • corrigir dados errados ou incompletos;
  • pedir que os apaguemos;
  • limitar ou opor-se ao tratamento;
  • receber os dados num formato que possa levar para outro serviço;
  • retirar o consentimento, sem afetar o que foi feito antes.

Para isso, basta escrever para geral@cubomagico.ai. Respondemos no prazo máximo de um mês.

Se achares que os teus dados não foram bem tratados, podes apresentar queixa à Comissão Nacional de Proteção de Dados em www.cnpd.pt.

Cookies

Este site não usa cookies nem ferramentas de análise ou publicidade.

Alterações

Se mudarmos esta política, publicamos a nova versão nesta página com a data de atualização.
